# JobYaari - Blog Management System

A fully responsive Blog Management System built using Core PHP, MySQL, jQuery, AJAX, HTML, CSS, and JavaScript.

This project allows users to browse blogs dynamically and provides an admin panel for complete blog management with AJAX-powered filtering and search functionality.

# Project Setup Steps

## Method 1 - Clone Repository (Recommended)

### Step 1: Clone Project

```bash
git clone https://github.com/jatingangwani/jobYaari.git
```

### Step 2: Move Project to XAMPP htdocs

Move the cloned folder into:

```
xampp/htdocs/
```

### Step 3: Import Database

- Open phpMyAdmin
- Create a database - with Name “jobYaari”
- Import the provided `.sql` file by drag & drop (located inside jobYaari/admin/DB/)

### Step 4: Run Project

Open browser:

```
<http://localhost/jobYaari>
```

# Security Features

The application is developed with security-focused architecture and backend validations.

## Authentication & Security

- Secure Admin Authentication System
- Session-based Login Security
- SQL Injection Protection on all forms and APIs
- All POST and GET requests are validated before database execution
- Input sanitization implemented across the application
- Protected database queries
- Form validation on both frontend and backend
- Unauthorized admin access restricted
- Secure file upload handling
- XSS prevention techniques implemented
- URL parameter validation

## Database Security

- All incoming request data is validated and sanitized before database operations
- SQL Injection checks applied before query execution
- Structured query handling implemented for safer database communication
- Invalid or malicious request blocking implemented
